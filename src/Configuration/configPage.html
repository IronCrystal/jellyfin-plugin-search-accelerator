Needs an external search provider, such as the Meilisearch plugin. Without one, Jellyfin searches as normal. Changes apply immediately; no restart needed.

Search
Master switch. Jellyfin normally waits for its own, slower database search even when the external provider has already answered. When on, Jellyfin's search only runs if the provider can't answer. When off, Jellyfin searches as normal.
A search that finds nothing returns immediately instead of running Jellyfin's database search. This is what makes empty searches (such as the Videos row) fast. The provider is checked against a known item first, so if it's down or its index is empty, Jellyfin's search is used instead. Turn this off if the provider's index is often out of date.
